# ビズリク｜就活イベントカレンダー

公開済みの就活イベントを開催日・エリア・卒年度で検索できるカレンダーです。

## 公開・更新

GitHub Pagesで配信します。GitHub Actionsが公開フィード3系統と受付停止APIを5分おきに確認し、画面は1分ごとに配信済みデータを再取得します。

GitHubの混雑で定期実行が遅れる場合があります。データ確認から10分が経過した場合や停止状態の取得が失敗した場合は、申込案内を停止します。停止中案件は閲覧のみです。原本のWordPress側の取込周期は別に存在します。

公開リポジトリで60日間操作がない場合、GitHubが定期実行を停止することがあります。Actionsで状態を確認し、必要時は再有効化してください。

## ソース

`bizreq-event-calendar-source.zip`は固定した依存関係・12件のテストを含むReact/Viteソースです。`.github/workflows/pages.yml`がSHA-256を確認して展開し、テスト・最新データ取得・ビルド・デプロイを実行します。ソースZIPを更新するときはワークフローのSHA-256も更新してください。

公開フィードに含まれる必要項目だけを使用し、認証情報や非公開シート、学生の登録情報は取得・保存しません。AIを使った常時監視は行いません。
